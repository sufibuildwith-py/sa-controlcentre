# SA Command — Operational Terminology & Operator Vocabulary

Standard terminology and colloquial mapping used by the owner (Mamu) and crew.

## Common Terms & Intent Mapping
- **"Sharma" / "Raju" / "Amaan"**: Refers to employees. Must be mapped through deterministic retrieval and disambiguated if multiple people share the name.
- **"Kitna baaki hai?" / "Kitna dena hai?" / "Pending balance"**: Maps to `READ_EMPLOYEE_FINANCE` -> `outstanding`.
- **"Royal" / "Royal event"**: Refers to an event production (e.g. "Royal Wedding" or "Royal Gala").
- **"Gear" / "Equipment" / "Stands"**: Refers to Headquarters inventory items.
- **"Azeem ne diya" / "Akash ne diya"**: Owner payer attribution (`AZ-2` / `AK-2`).
- **"Aaj" / "Kal" / "Parso"**: Application timezone (`Asia/Kolkata`) relative dates.
